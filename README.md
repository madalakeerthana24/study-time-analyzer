# 📚 Study Time Analyzer

A Flask-based web application that helps students analyze their daily study habits by tracking the number of hours spent on different subjects. The application generates a graphical report, identifies the strongest and weakest subjects, calculates study time percentages, and provides personalized study suggestions.

---

# 📖 Project Overview

Effective time management is essential for academic success. This project enables students to record their daily study hours for different subjects and instantly view a detailed analysis of their study patterns.

The application automatically calculates:

* Total study hours
* Percentage of time spent on each subject
* Strongest subject
* Weakest subject
* Personalized improvement suggestion
* Motivation message
* Study time graph

---

# ✨ Features

* ✅ Add study hours for multiple subjects
* ✅ Automatic study time analysis
* ✅ Percentage calculation for each subject
* ✅ Identify strongest subject
* ✅ Identify weakest subject
* ✅ Personalized improvement suggestions
* ✅ Motivational feedback
* ✅ Dynamic bar chart generation
* ✅ Simple and responsive user interface

---

# ⚙️ How It Works

1. Enter:

   * Subject Name
   * Study Hours

2. Click **Add**.

3. The application:

   * Stores the data in a CSV file
   * Calculates total study hours
   * Computes percentage contribution of each subject
   * Finds the strongest and weakest subjects
   * Generates a study report
   * Displays a bar chart

---

# 📊 Output

The application displays:

* Subject-wise Study Hours
* Percentage Distribution
* Strongest Subject

# 🚀 Installation

## Clone the Repository

```bash
git clone https://github.com/your-username/study_time_analyzer.git
```

## Navigate to the Project Folder

```bash
cd study_time_analyzer
```

## Install Dependencies

```bash
pip install flask matplotlib
```

## Run the Application

```bash
python app.py
```

## Open in Browser

```
http://127.0.0.1:5000
```
